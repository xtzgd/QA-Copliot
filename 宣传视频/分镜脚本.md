# QA Copilot 介绍视频 · 分镜与旁白脚本

目标时长约 2 分 40 秒。主体是真实录屏，开场、痛点、结尾用动画包装。旁白交给 AI 配音生成，字幕与旁白同文。

## 一、录制前准备

1. 构建插件并在 `chrome://extensions` 以「加载已解压的扩展程序」载入构建产物（输出目录以 `scripts/build.ts` 为准）。
2. 终端运行 `npm run smoke`，打开 `http://127.0.0.1:4173`，这是自带的演示页，有表单和 200/400/500/慢请求按钮。
3. 用一个干净的 Chrome 用户配置录制：隐藏书签栏、关闭其他标签页、关闭系统通知，窗口调成 1920×1080。
4. 设置页提前配好：
   - 禅道集成：登录测试用禅道，点「一键从当前浏览器获取」，选关联产品，点「保存禅道设置」。
   - AI 大模型：模式选「大模型 API」，填好后点「测试大模型连接」「保存 AI 设置」（自然语言测试需要）。
   - 快捷登录（可选）：配一个测试环境账号。
5. 录制前清空历史 Session，让首页数字从 0 开始。
6. 禅道地址、Token、真实账号姓名不要出镜，出镜了后期打码。

## 二、录制要求

每个镜头单独录一个文件，文件名用下表的编号，例如 `S03_回放与导出.mov`，放进本目录的 `素材/` 文件夹。开头结尾各停 2 秒不动，鼠标移动放慢，点击前在按钮上停半秒。不用录声音。

推荐用 macOS `Cmd+Shift+5` 录制所选区域，或 OBS 输出 1080p 30fps。

## 三、分镜

| 编号 | 时长 | 画面类型 | 操作步骤 | 旁白 / 字幕 |
| :--- | :--- | :--- | :--- | :--- |
| A1 | 8s | 动画 | 片头 Logo 与标题 | 这是 QA Copilot，一个装在 Chrome 侧边栏里的测试助手。 |
| A2 | 10s | 动画 | 四个痛点依次弹出 | 复现步骤靠回忆，截图和接口手动拼，禅道和开发者工具来回切。测试的时间，很多花在了搬运上。 |
| S01 | 10s | 录屏 | 打开演示页 → 点扩展图标打开侧边栏 → 点「开始测试」，状态卡开始计时 | 打开要测的页面，点一下开始测试，记录就开始了。 |
| S02 | 15s | 录屏 | 在演示页表单填用户名、手机号，选角色，勾选启用；侧边栏「操作」计数上涨 → 切到底部「测试」页，展示时间线 | 点击、输入、选择，都会自动记成时间线，不用再手写复现步骤。 |
| S03 | 15s | 录屏 | 「测试」页点「一键回放」，顶部出现「回放中」进度条，结束弹出回放完成提示 → 点「Playwright」导出脚本，打开下载的 `.spec.ts` 停 2 秒 | 记录下来的操作可以一键回放，也能导出成 Playwright 脚本，直接接进自动化。 |
| S04 | 15s | 录屏 | 演示页依次点「Fetch 500」「XHR 400」「发起慢请求 (3.5s)」；首页「异常」数字变化 → 切到「API」页，点筛选「5XX」「慢请求」 | 接口请求自动抓取，500、400 和慢请求会直接标出来，一眼就能看到。 |
| S05 | 15s | 录屏 | 「API」页 Network Mock 卡片点「新建规则」→「保存并启用」→ 再点「Fetch 200」，列表出现 MOCK 标记 → 展开一条请求点「编辑重发」，改参数后「发送」 | 不等后端，也能用 Mock 造出异常返回。改完参数一键重发，调接口更快。 |
| S06 | 15s | 录屏 | 首页点「🚨 发现问题」→ 快照页显示「已保存问题现场」，等待「上下文采集已完成」，展示操作记录、接口请求、控制台日志、页面截图四项 | 发现问题，按一下。截图、前后操作、接口和日志，现场一次保存。 |
| S07 | 12s | 录屏 | 点「查看详情并生成 Bug」→ 在 Bug 详情选严重程度和指派人，展示自动生成的复现步骤 → 点「🚀 提交到禅道并打开」，新标签打开禅道 Bug 页 | 复现步骤自动生成，确认后一键提交到禅道，附件一起带上。 |
| S08 | 18s | 录屏 | 首页点「智能填表」→「识别当前网页表单」→ 选「🎯 默认测试数据」→「生成填写方案」，停在方案预览 →「执行填充」，表单被填好，报告显示「已写入并回读」→ 点「撤销」，表单恢复 | 重复的表单交给它。识别字段，生成方案，你确认后再填。填完自动回读校验，不满意还能撤销，也不会替你点提交。 |
| S09 | 12s | 录屏 | 首页「自然语言测试」输入框输入一句测试目标，例如「在用户名输入 qa_demo 并选择角色」→ 点「执行」→ 等到显示「测试通过 (PASS)」→ 点「查看明细」 | 用一句话描述测试目标，AI 会自己操作页面并判断结果。 |
| S10 | 8s | 录屏（可选） | 首页快捷登录卡片选环境与账号，点「一键直达并登录」；或点「悬浮小窗」展示独立窗口 | 常用环境一键登录，侧边栏也能变成悬浮小窗，不挡页面。 |
| A3 | 8s | 动画 | 功能回顾与产品名 | QA Copilot，把重复劳动留给工具，把判断力留给你。 |

S10 是可选镜头，不录的话总时长约 2 分 30 秒。

## 四、需要特别注意的镜头

S07 推送禅道依赖真实禅道。没有测试环境的话，改为点「复制 Markdown」，再粘贴到一个空白文档里展示，旁白改成「复现步骤自动生成，一键复制成标准 Bug 报告」。

S09 依赖 AI 网关，结果不稳定时多录几遍，挑一次通过的。

S08 在本地启发式规则模式下也能跑，不需要 AI 网关。

## 五、交给我之后的流程

素材放进 `宣传视频/素材/` 后告诉我。我会按上表剪辑，生成 AI 配音和字幕，加背景音乐，配上动画片头片尾，导出 1080p mp4。AI 配音默认用中文女声，语速略快于正常朗读；想换男声或指定风格可以提前说。
