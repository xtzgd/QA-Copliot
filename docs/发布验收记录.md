## 1. 发布门槛与核心原则 (Release Gateways)

发布必须严格满足以下硬性指标，**绝对禁止以“100% 单测通过”替代真实 Chrome 浏览器验收结论**：

1. **零阻断缺陷**：P0（数据串扰、污染、误操作页面）与 P1（运行失控、状态丢失、录屏损坏）问题遗留为 0；
2. **两轮端到端通过**：在真实的 Google Chrome 浏览器环境中，加载未打包扩展（Unpacked Extension），关键场景（录屏、填表、回放、慢请求、取证导出）必须连续完成两轮完整的真实操作验证；
3. **环境隔离与数据安全**：必须使用独立的 Chrome Profile 运行验收，严禁用开发者日常工作 Profile 或生产账号；
4. **已知限制明确文档化**：所有 P2 遗留项或尚未支持的特性（如非顶层 iframe、复杂第三方虚拟列表等），必须在发布说明和界面上提供明确提示。
